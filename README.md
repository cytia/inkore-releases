## 这是什么

砚客 Inkore 是一个为创作者设计的 Markdown 写作工具。它轻量、简洁，功能全面。编辑排版实时渲染，所见即所得。它专为创作者优化，支持分页编辑文档、跨文件全局搜索，还为国内创作者提供更优化的多种导出方案。它没有账户系统，数据全部保留在用户本地。它只通过 MCP 调用 AI 工具作为工作助理。

## 核心功能

- **所见即所得，实时编辑** — 实时渲染排版，无需分屏。泡泡工具栏与右键菜单完成排版，支持多色文本标记、可编辑表格、浮窗式注脚。
- **仓库管理，分页编辑** — 指定本地文件夹创建仓库，文件自动保存，支持双文档同屏编辑、资源管理器定位。
- **跨文件搜索替换** — 在全仓库搜索内容、按文件分组跳转定位，或直接批量替换。
- **快照管理，版本恢复** — 手动快照 / 自动记录文件历史，误改可迅速回滚，还原前自动保留退路，快照回收站可找回误删。
- **多平台导出分发** — 更符合国内创作生态的导出方案，详见下方导出矩阵。
- **MCP 功能桥接** — 开放本地桥接端口，把 Claude Code 等主流 AI 工具变成创作助理（读取仓库、编辑文档、导出分发、自定义模板）。

## 导出矩阵

| 格式 | 说明 |
|---|---|
| **Word** (.docx) | 可自定义模板，内置文学投稿 / 论文期刊两套子模板 |
| **PDF** (.pdf) | 出版级模板，适合分发、打印、长期保存 |
| **HTML** (.html) | 基础模板套用编辑器排版，Pro 模板可自定义 |
| **长图** (.png) | 生成适合社交平台转发的长图，Pro 模板可自定义排版 |
| **公众号** | 一键复制排版到微信公众号，多种模板样式 |
| **平台文案** | 一键复制排版到知乎、小红书 |
| **小红书图文** (.png ×N) | 自动分页成图文卡片，可自定义排版与卡片比例 |

## 外观

- **自选版式** — 文本宽度、行间距、段间距、标题对齐均可自选。
- **自选主题** — 内置四套符合 WCAG 护眼标准的主题，可基于 36 套预设主色自定义。
- **自选字体** — 内嵌思源宋体、朱雀仿宋、汇文明朝、小赖字体，也支持系统安装的任意字体。

## 隐私

- **无账户** — 没有账户系统，不采集用户数据。
- **全本地** — 数据保存在本地仓库；线上试用版内容通过浏览器缓存保存。
- **数据同步** — 不内置同步，可在 OneDrive 等网盘中创建仓库实现同步。
